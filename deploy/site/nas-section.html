NAS / 群晖版当前 {{VERSION}}

适合装有 Docker Compose v2 的 x86_64 或 ARM64 NAS。24 小时在线，多设备共用。

当前稳定镜像 ghcr.io/wuli2025/polaris_coworker:latest，Build {{REVISION_SHORT}}。旧架构只迁移一次，以后直接在北极星“更新”页面完成。

一次迁移 旧版 2.7 / 2.8：只迁移这一次

也适用于没有 Git 目录的旧安装和第一次安装。在 NAS 的 SSH 终端粘贴一行：

NAS 终端
curl -fsSL https://llmwiki.cloud/docker/nas-bootstrap.sh | sudo sh
数据不会被搬走或删除。脚本先拉取新镜像，再停止旧容器；它沿用原数据挂载，不递归改 NAS 文件权限。新容器未通过就绪与版本校验时，会自动恢复旧容器。
迁移成功后，旧容器会以 polaris-web-legacy-日期 的名称停止保留，方便恢复。确认数据无误后再自行删除；脚本不会替你删除。
已有 Git 目录？点这里用原目录更新
在原来运行 Polaris 的仓库目录执行：
原 Polaris Git 目录
git switch main
git pull --ff-only origin main
sudo sh docker/nas-bootstrap.sh

以后都在页面 已经是 {{VERSION}}：以后直接在页面更新

  1. 打开北极星 → 更多 → 更新
    点“检查更新”。即使版本号仍是 {{VERSION}}，只要 Build revision 更新，也会正确发现新镜像。
  2. 点“立即更新容器”
    隔离的更新服务会拉取官方镜像并替换 polaris-web，页面短暂断线后自动恢复。
  3. 核对运行版本
    页面会等到新 boot、目标 revision 和服务就绪全部命中才报告成功；也可在 NAS 执行下面命令核对。
核对 {{VERSION}}
POLARIS_PORT="$(sudo docker inspect -f '{{with (index .HostConfig.PortBindings "8080/tcp")}}{{(index . 0).HostPort}}{{end}}' polaris-web)"
curl -fsS "http://127.0.0.1:${POLARIS_PORT}/api/build"
没有额外口令步骤。NAS 保持当前免口令体验；容器之间的更新通信由部署文件内部处理，不需要记忆、填写或复制任何密钥。Docker socket 只进入固定版本的 updater sidecar，不进入 Polaris App。
