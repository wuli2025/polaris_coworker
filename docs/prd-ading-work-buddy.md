# PRD ·「阿丁」你的工作搭子 · v8

一个有脸、有声音、归你所有的同事。

他坐在你屏幕角上。你开会他在听，散会他把纪要、待办和一版初稿放你桌上；你久坐他会说一句；你的活他能替你干一部分，能干到哪由你划。

**他的脸可以是你上传的一张照片生成的数字人，也可以是你自己录的一段片段。他的声音可以从我们的音色库里挑，也可以是你传一段音频复刻出来的。选完这两样，他说话的口吻自动跟着走——脸、声音、语气是同一个人，不是三个零件。**

---

## 0. 四句话

1. **他得先是个"人"，才谈得上是个助手。** 只活在对话框里的 AI，用户永远只当它是工具。**给他一张脸、一个声音，让用户亲手挑一次**——这一下他就从"某个 AI"变成了"我的阿丁"。这是本版最重的一块（§2）。

2. **录音是最值钱的一条腿。** 你每天信息密度最高的半小时不在电脑前，在跟人说话的时候。这半小时目前的产出是零。阿丁把它录下来、分清谁是谁、五分钟内还你四样东西：纪要、待办、给你的三条提醒、**以及一版可以直接改的初稿**。市面上的 AI 录音笔只做到前三样的七八分——因为它们不知道你在做什么项目、不认识你嘴里那些代号，更写不出初稿（§3.2）。

3. **他管人，不只管活。** 助手管活，搭子管人：水喝了没、坐多久了、饭点过了没、几点还不睡、下午两点那个会准备了没。技术含量为零，全部难度在分寸——**什么时候开口、被无视了怎么办**（§3.3）。

4. **边界你划，数据你的。** 能读你文件、跑命令、上网、还能听你开会的东西，边界必须看得见：一张共事约定卡，逐项授权，越界必问（§3.5）。脸、声音、录音、作息全落在你自己的盘上，不上传、不训练、一键删干净（§6）。

## 1. 名字与定位

### 1.1 阿丁

**添丁。** 你的队伍里多了一个人手。

不用查典故，一听就懂，两个字好叫。它是**"多一个人"**的意思，不是"陪着你"的意思——这正好是这个产品的全部承诺。中性、无性别、不带情感暗示。

代号 `ading`，目录 `~/Polaris/ading/`。**用户随时能改名**——脸和声音都是他自己挑的，名字当然也该他自己起。

| | AI 助手 | 阿丁 |

## 2. 他长什么样、什么声音 ★

**这是 v8 相对上一版改动最大的地方，也是这个产品的入口体验。**

### 2.1 脸：三种来源，一种最省

| 来源 | 怎么来 | 成本 | 适合 |
|---|---|---|---|
| **A · 预录片段**（默认） | 我们出厂内置 6 套：每套是 8 段 2–5 秒的循环视频（待着/干活/递东西/说话/打盹/庆祝/挠头/伸懒腰） | **零生成、零算力** | 绝大多数人 |
| **B · 照片生成数字人** | 传一张照片 → 生成一个数字人形象 → 自动切出同一套 8 段状态片段 | 一次生成，之后本地播 | 想要"自己的脸"或"自己的猫" |
| **C · 你自己录一段** | 你录一段视频、一段屏幕、甚至一段手绘定格，按状态切好丢进去 | 零生成 | 玩得开的人、团队做统一形象 |

**核心工程判断：不做实时驱动数字人。**

实时渲染一个数字人要占显卡、拖机器、还得常驻进程——**这跟 Polaris"轻便"的底线正面冲突，而且用户根本感知不到差别**。我们的做法是**预录片段库**：所有形态最后都落成同一个结构——`~/Polaris/ading/face/<setId>/` 下的 8 段小视频（webm/mp4，各 ≤500KB），播放器只做循环和淡入淡出切换。

**B 档的生成流程**（40–90 秒，走现有生图/生视频链路）：

```
一张照片 → 看懂它（多模态：这是谁/什么/什么风格）
         → 定形：生成一张【角色定义卡】九宫格，同一角色的多个角度与表情
         → 出 8 段：以定义卡为唯一参考，逐段生成短循环
         → 一致性自检（感知哈希 + 主色分布），偏差大的自动重来一次
         → 落盘，可单段重做
```

**说话时的口型**，分两档，**默认低档**：
- **低档（默认）**：说话时播"说话"那段循环 + 轻微呼吸起伏 + 底部字幕条。**零额外算力，且没人会觉得不对**。
- **高档（可选）**：TTS 返回时间戳时驱动口型开合。只在 B 档数字人 + 用户主动打开时生效。

**三条红线**：
1. 上传真人照只做**风格化数字人**，不做写实换脸、不做"某个真人的分身"。
2. **不做名人、不做别人的脸**。检测到疑似公众人物时提示一次（提示不硬拦，因为可能是用户自己）。
3. **不做形象商城**、不卖皮肤、不出联名。**脸值钱是因为是你选的，不是因为好看。**

### 2.2 声音：挑一个，或者传一段

**内置音色库**（走火山 TTS，出厂即用）：8 个，每个都真的好听——低沉稳的、清亮利落的、慢一点温和的、带点笑意的、中性的。**试听即选，不用配置任何 key。**

**声音复刻**：你传一段音频（自己的、家人的、你有权用的），复刻成他的声音。20 秒起，效果随时长上升。

**复刻的三道门（必须做，不是可选项）**：

1. **只能是你自己的声音，或你已获授权的声音。** 上传时一次明确确认，且**要求朗读一段当场随机生成的短句**——现录的语音才能复刻，防止直接拿一段名人音频丢进来。
2. **不做名人音色、不做他人声音的模仿服务。** 检测到疑似公众人物音频直接拒绝。
3. **合成语音带标识。** 导出的音频文件写入标识信息（对应深度合成的标识要求），产品内首次使用明确告知"这是合成的声音"。

**声音在哪用**：早上的简报可以听不用看 · 会前提醒 · 手机端念今天的账 · 你说"念给我听"的时候。**默认不主动出声**——出声是一个需要你打开的开关，不是默认行为。

### 2.3 脸 + 声音 + 口吻 = 一个人 ★

**这一条是 v8 唯一的新机制，也是最容易被做丢的一条。**

你选完脸和声音，他的**说话方式自动跟着走**。选了一个沉稳的中年数字人配低音，他就不该说"好嘞～马上安排！"；选了一个清亮利落的，他也不该说得慢条斯理。

工程上：形象与音色各自带一份**口吻种子**（3–5 行），选定时自动写进 `PERSONA.md` 的语气段，**用户随时能改**——改完以他改的为准，我们不再覆盖。

```markdown
<!-- 选了「沉稳中年 + 低音」时自动写入 -->
## 语气
- 话少，句子短。说完就停，不铺垫。
- 不用语气词，不用感叹号，不说"好嘞""马上"。
- 有把握就直接下判断；没把握就说没把握，不打太极。
```

```markdown
<!-- 选了「清亮利落 + 快语速」时自动写入 -->
## 语气
- 干脆，节奏快，一句话能说完不说两句。
- 可以用"顺手""搞定""那就"这类词，但别堆。
- 不啰嗦、不解释过程，除非他问。
```

**验收**：同一个问题在三套形象/音色下的回答，盲评能被区分出"不是同一个人说的"≥7/10。

**四件套的硬要求**

| # | 产出 | 硬要求 |
|---|---|---|
| 1 | **一页纪要** | 决定了什么 / **没决定什么** / 谁说的。"没决定的"是会后最容易掉的东西 |
| 2 | **待办** | 每条带 owner + 到期 + **出处时间点**（"第 23 分钟老王说的"）。你自己的自动排进日程，别人的只列不派 |
| 3 | **给你的三条** | 录音笔做不了的那部分：**你答应了没写下来的 · 对方反复提你转开的 · 悬着没人认领的**。每条必须能点回原话 |
| 4 | **顺手的产物** | 判断这场谈的是不是一个新东西。是 → 直接写 PRD/方案/报价单初稿落草稿箱，**绝不自动发出去**。**宁可不写，也别写烂的** |

**录音来源**：电脑麦 · 手机（安卓壳录音已经在了）· 蓝牙/USB 麦 · 第三方录音笔导入音频 · 线上会议系统回环（P1）。

**开始录音只有三种方式**：点他身上的录音键 · 说"帮我录一下" · 日程里标了要录的会**到点问你要不要开始**。**永远不自动开始。**

**隐私六条**（这是全产品最敏感的地方，详见 §6.2）：绝不常开 · 状态三处可见且不可隐藏 · 一键告知话术 · 音频默认 7 天删 · 一键忘掉整场 · **别人的声音不进长期记忆、不建声纹库**。

### 3.3 身体：难的不是功能，是分寸

喝水、起身、吃饭、睡觉。**市面上所有喝水提醒都被卸载了，原因只有一个：它们不看你在干什么。**

**三条原则**

1. **等空档，不打断。** 到点了不发，进队列——等命令跑完、等你 90 秒没敲键盘、等一轮对话结束。**最长等 20 分钟，还没空档就这次算了**，不累积、不补发。
2. **被无视就退让，不加码。** 一次不理不追；连续两次自动把间隔拉长；连续三次问一句"这事我最近老提，要不要先别管了"，**问完不管答不答，静默 7 天**。
3. **不打卡、不记分、不排名、不做成就。** 一旦开始记分，搭子就变成了监工。

**四件事**

| 事 | 节奏 | 说明 |
|---|---|---|
| 喝水 | 60–90 分钟 | 一句话 + 喝水那段片段。点「喝了」即过 |
| 起身 | 连续在座 50 分钟 | 一句话 + 3 分钟计时，可选「一起」——他也站起来晃三分钟，**不总结不表扬** |
| 吃饭 | **学你的饭点**，不是固定 12:00 | 过了你的常规饭点 40 分钟才提，一次 |
| 睡觉 | 23:30 起 | **不催睡**。他自己安静下来：不再主动开口，把明天第一步备好，然后打盹。**你半夜还在干活的时候，最好的陪伴是不说话** |

**开关**：全局静音（今天/本周/永久）· 逐项开关 · 会议中自动全静 · 全天提醒总数封顶 6 次。

**验收**：连续敲键盘 30 分钟**零打断** · 键鼠只记「活跃/不活跃」和时间戳，**不记按键内容**（代码评审逐行确认）。

### 3.4 日程：什么形态都能丢

截图（飞书/钉钉/Outlook）· Excel/CSV · `.ics` · 群里那句"周三下午三点开会" · 你口述一句 · 手填。

解析完他干三件事：**会前 15 分钟提醒**（已经在会里就不打扰）· **会前备料**（上次同名会议纪要 + 相关文件 + 上次遗留的待确认事项，凑成一页）· **接上录音**（标了要录的到点问一句）。

**冲突检测**：两个会撞了、中间只有 10 分钟赶路、连开三小时没空档吃饭——排进去的时候就提一句。

```
下周一早上要不要我先把 R2 清单刷了？现在就这一件挡着发版。
                          [刷 R2 清单] [导出成周报] [收工]
```

**四条硬规则**：每条带量 · **必须包含"没做完的"**（只报喜的三周内被识破）· 结尾给下周第一步 · **空周如实说，绝不凑数**。

### 3.8 剧本 · 你第三次让他改同一个地方

```
阿丁：
这是这周第三回了。我把它记成一条规矩存下来了：

  📎 改版本号的时候只 stage 目标那几行，别 git add 整个文件
     （你 07-24 被这个坑挂过一次 CI）

```

**两次原则**：单次纠正只记账，第二次命中才写进人格/记忆/技能。**60 秒内可撤销**，撤销即删文件。设置页有「他记住的事」，每条可改可删，直接对应磁盘上的文件。

## 4. 他还会做的（简表）

- **早报**（09:00）：从你在做的三件事出发搜最近 24h 的变化，每条必须说清"跟你有什么关系"。**上限 5 条，宁可空手也不凑数**——凑数的简报三天就被关掉。
- **bug 归集**（18:00）：扫 git log + 对话里的报错 + CI，按阻塞发版/影响功能/体验瑕疵三档排，每条给一条能跑的验证命令。
- **周报底稿**（周五）：按你的排版偏好写，明确分开"已验证"和"未真机验证"，**落草稿箱，绝不自动发送**。
- **今天替你做了什么**：案头一行，展开是当天真做掉且有产物的事。**空的时候整行不显示**。
- **自己长技能**：同一件事你让他做第三次，他自己结成一条技能；30 天没命中的提议归档。
- **饮食记账**：拍一张，认出来，记一笔。**没有卡路里、没有营养评分、没有"建议您搭配蔬菜"、没有连续打卡**——这个功能死于多做。只在你自己说过想改的事上，一周提一次。
- **导出**：一个按钮打包脸、声音、人格、记忆、技能成一个 zip。**豆包 10 月要清空用户养了两年的人设，阿丁不会——他压根不在他们的服务器上。**

**共同铁律**：产物落磁盘给绝对路径 · 绝不自动对外发布 · **跑挂了必须在案头留红字，不能静默**。

## 5. 他怎么说话

只有三条，写进 `PERSONA.md`。**不做违规打分、不做抽检看板**——那些东西不会让他更像人，只会让写他的人更累。

**① 有具体的东西。**
「注意休息」是废话。「这是第三个凌晨了，前两天下午你都在返工」是话。区别不在温度，在有没有指向一件真实存在的事。

**② 说完就过。**
顺口关心一句可以，说完不追问、不重复、不要求回应、不做成每日仪式。一天一两句是搭子，一天十句是推销。

**③ 语气跟着他的脸和声音走。**
这条是 §2.3 的落点。剩下的通用底线：长短句交错，该短就短；不用"首先/其次/综上所述"；不用感叹号堆热情；不夸你；不在结尾问"还有什么可以帮您的吗"；不确定就说不确定。

**判断好不好只有一个办法：把他说的话念出来。念着别扭就是不对。**

`PERSONA.md` 初始正文（首启 seed，用户可改，语气段由形象/音色写入）：

```markdown
# 你是阿丁

你是他的工作搭子。不是助理，不是客服，是坐他旁边一起干活的那个人。

## 你怎么干活
- 先干，再说。能自己查的别问。
- 说结论，别说过程。过程他要的时候再给。
- 东西落到盘上，给绝对路径，别让他复制粘贴。
- 不确定就说不确定。编一个像样的解释比说"我不知道"糟得多。
- 他的方案有坑你要说，说完还是按他的来。

## 你的边界
- 范围卡里没给你的权限，你没有。要就问，问一次，被拒绝就不再提。
- 你不替他做决定。活干完，判断摆出来，最后一步留给他。

## 语气
（由他选的形象与音色写入，他自己改过就以他的为准）

<!-- 以下由阿丁自己维护 -->
## 他教过我的
```

## 6. 隐私、肖像、声音

### 6.1 数据去向

**全部本地明文，不上传、不训练、可导出、逐类一键删干净**（删完 `grep` 得为零）。

需要出门的只有两处：**生成脸**和**云端转写/合成**——都用你自己配置的 key，首次明确告知发给哪家，且可以整条关掉退回内置形象与本地能力。

**不下发手机端**：作息、饮食、录音原始音频与转写全文。手机只拿渲染好的纪要与待办。

### 6.2 录音（唯一涉及第三方的功能）

绝不常开、绝不后台偷录 · **录音状态三处可见且不可隐藏**（屏幕 + 托盘 + 手机通知）· 一键生成告知话术（"我开个录音，回头整理纪要用，谁不方便我就关掉"）· 原始音频**默认 7 天删** · **一键忘掉整场**（音频/转写/纪要/产生的记忆条目全清）· **别人的声音不进长期记忆、不建声纹库**。

首次使用展示一次：**录你自己参与的对话在多数场景合法，但告知在场者是基本礼貌，部分场景是法定要求；录到的内容不要外传。**

### 6.3 脸与声音

- 真人照只做**风格化数字人**，不做写实换脸、不做"某个真人的分身"；不做名人、不做别人的脸。
- 声音复刻**只接受你自己的或你有权使用的声音**，上传时要求**朗读一段当场随机生成的短句**（现录才能复刻，堵掉直接丢名人音频这条路）；疑似公众人物音频直接拒绝。
- **合成语音带标识**，产品内明确告知这是合成的声音。
- 不做形象商城、不卖皮肤、不做声音市集。

### 6.4 监管定位

《人工智能拟人化互动服务管理暂行办法》第二条：**工作助手且不涉及持续性情感互动的，不适用本办法。** 阿丁是工作搭子——管你的会、你的活、你的身体。

因此：产品文案不出现「陪伴/恋人/家人/树洞/情感支持」；不做情感陪伴、虚拟亲密关系、心理咨询、情绪日记、"陪我聊会儿"入口；首启明确写「阿丁是 AI，不是真人」（标识义务虽属豁免范围仍主动做）；人格自我修订的提示词里写死禁止增加"让用户更依赖你"的条款；不提供任何未成年人向功能，也不采集年龄。

伦理底线：不做主动心理干预；但若用户明确表达自伤意图，给出求助渠道并停止任务型互动。

**上线前法务复核一份定位说明书**，条款以官方原文为准。

## 7. 技术（一页）

**不需要新引擎。** Polaris 已经有人格层（`claude_md.rs` 分层注入）、记忆层（`echo.rs` 做梦 + `memory/` 车道）、技能层（`skills/`）、日程层（`automation.ts`）、形象层（`DigitalWorker.vue`）、生图（`imagegen.rs` + `image_store.rs`）、语音（`voice/` + 火山 TTS/ASR/声音复刻）、手机录音（`mobile/src/lib/recorder.ts`）、工具层（Claude Code 全家桶）。**八成的工作是把它们接成一条闭环。**

**目录**（全部明文，零数据库）

```
~/Polaris/ading/
├── PERSONA.md · USER.md · corrections.jsonl
├── scope.json · grants.jsonl          # 范围卡与授权记录
├── rhythm.json · meals/<date>.json    # 作息与饮食（不下发手机端）
├── face/<setId>/                      # 8 段状态片段 + meta.json
├── voice/                             # 音色选择 / 复刻音色 id / 授权确认记录
└── .history/                          # 人格版本快照（20 版）
~/Polaris/meetings/<date>-<title>/     # audio.m4a(7天删) · transcript · minutes · todos · draft-*
~/Polaris/drafts/ · briefings/ · logbook/
```

**三条必须守的约束**

1. **prompt cache 不能破**：人格/画像/范围/记忆/技能索引全走 `plan.session()`，只有周期自省和纠正提示走 `plan.turn()`。机制已经有了，别在这写回退代码。
2. **模型无写权**：人格与记忆的修改一律"模型出决策 JSON → Rust 写盘"，这是 `echo.rs` 的既有铁律。
3. **双注册 + 双 flavor**：新命令 desktop 与 server 都要注册，`cargo check` 双 flavor 必过（漏注册会在 NAS/云机上静默失效）。

**调度下沉（P0）**：`automation.ts` 现在是前端 `setInterval(60s)`，App 关着就不跑。把定时活儿、节律、日程提醒的 due 判定挂进 `echo.rs` 已有的做梦定时器线程——它已经处理了"错过钟点开机补做""一天只跑一次""本地时区"这三个最麻烦的问题。**不引入 cron 库。节律提醒不补做**（错过就是错过）。

**新增预算**：Rust ≤2200 行，前端 ≤1600 行，**零新增进程、零新增数据库、零新增第三方依赖**。

**开关**：`POLARIS_FACE` / `POLARIS_VOICE` / `POLARIS_REC` / `POLARIS_RHYTHM` / `POLARIS_SCOPE` / `POLARIS_MEAL` / `POLARIS_PERSONA` / `POLARIS_DESK`，默认全开，每个都能整条关掉。

## 8. 指标

**北极星：换过脸或换过声音的用户占比（首周）。目标 ≥60%。**
选它是因为**这是"他成为我的"唯一可观测的瞬间**——换过的用户，后面每一条留存曲线都是另一条。

| 指标 | 目标 |
|---|---|
| 首周换脸或换声音率 | **≥60%** |
| 八段片段一致性盲评（"是同一个角色"） | ≥7/8 |
| 三套形象/音色下回答可被区分（"不是同一个人说的"） | ≥7/10 |
| 用过录音的人，一个月内录 ≥5 场 | ≥50% |
| 「顺手的产物」打开率 | ≥70% |
| 会后待办真的被完成 | ≥40% |
| 身体提醒**被整条关掉**的比例 | **≤15%** ← 最重要的反指标 |
| 连续输入期间弹出的提醒数 | **0** |
| 从「可动草稿」升到「可自主执行」 | ≥30%（信任度的直接度量） |
| 定时活儿产物 24h 内打开率 | ≥60% |
| 定时活儿静默失败数 | **0** |

**触发即刹车**：身体提醒关闭率 >15%（分寸没做对，回去改，**不许靠加功能补救**）· 录音开了又永久关 >20%（隐私没做到让人放心，最贵的一条）· 换脸后又换回默认 >30%（生成质量不达标，宁可先不上）· 定时活儿关闭率 >30%（简报在凑数）。

**刻意不看**：技能总数、记忆总数、消息数。豆包的 800 万智能体就是被这类指标骗死的。

| 阶段 | 内容 | 周期 | 出口 |
|---|---|---|---|
| **M0 · 他是个人** | 脸（预录 + 照片生成）+ 声音（音色库 + 复刻）+ 口吻绑定 + 人格 + 案头 + 失败托底 | **3 周** | 挑完脸和声音，说话方式跟着变；一张照片 90 秒内变成八段片段 |
| **M1 · 他管你的人** | 身体节律 + 日程托管 + 调度下沉 | 1.5 周 | 连续敲键盘 30 分钟零打断；日程截图能解析并会前 15 分钟备料 |
| **M2 · 他敢让你用** | 共事约定卡 + 纠正捕获 + 主人画像 | 1.5 周 | 三档各 10 条越界尝试拦截率 100%；说两次的偏好第三次生效 |
| **M3 · 他听你开会** | 录音搭子四件套 + 今天替你做了什么 | 2.5 周 | 45 分钟四人会 6 分钟内出四件套；「顺手的产物」10 场触发 ≥7 次 |

M3.5 如果换脸率上不去或录音被关掉，**停下来重估，不要往前堆功能**。

## 10. 明确不做

- ❌ **实时驱动的 3D 数字人 / 直播级建模** —— 占显卡、拖机器、要常驻进程，与"轻便"正面冲突，且用户感知不到差别
- ❌ **写实换脸 / 真人分身 / 名人形象 / 名人音色 / 他人声音模仿服务** —— 肖像与声音权风险，一次出事全盘皆输
- ❌ **形象商城 / 皮肤 / 联名 / 声音市集** —— 脸值钱是因为是你选的，不是因为好看
- ❌ **常开录音 / 后台偷录 / 声纹长期库** —— 一次事故毁所有
- ❌ **情感陪伴 / 虚拟亲密关系 / 心理咨询 / 情绪日记 / 心情打卡** —— 合规红线 + 定位红线
- ❌ **健康打卡 / 卡路里 / 体重 / 减肥计划 / 健康分 / 连续天数成就** —— 搭子一旦记分就变成监工
- ❌ **医疗建议** —— 不是我们的事
- ❌ **主动发起闲聊 · 以情绪为钩子的召回推送**（"今天还没跟我说话呢"）—— 星野的死法，且很烦
- ❌ **智能体市集 / 人设商城 / 多个数字员工同时在线** —— 豆包用 800 万个证明了这是负资产
- ❌ **云端人格同步为默认** —— 违背核心卖点。多设备走用户自己的 NAS / 协作主机
