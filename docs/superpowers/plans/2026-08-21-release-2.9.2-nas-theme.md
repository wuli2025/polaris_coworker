# Polaris 2.9.2 NAS Readability Release Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish Docker build 2.9.2 with a readable warm-white NAS manager in light themes, a high-contrast dark equivalent, and a verified one-time upgrade path for NAS installations still on 2.7.0.

**Architecture:** Keep NAS connection behavior unchanged. A small pure TypeScript palette module supplies the real CSS custom properties consumed by `NasManager.vue`; unit tests calculate WCAG contrast from those production palette values. Version metadata is synchronized across npm, Cargo, and Tauri before the commit is pushed to `main`, which triggers the existing multi-platform Docker workflow.

**Tech Stack:** Vue 3, TypeScript, Pinia, Vitest, CSS custom properties, Tauri 2, Cargo, GitHub Actions, GHCR.

**Spec:** User-approved bounded design in this conversation on 2026-08-21: warm-white/high-contrast NAS dialog in light themes, readable dark theme, version 2.9.2, and Docker remote-update publication.

## Global Constraints

- Do not change NAS save/connect/disconnect data flow or credentials handling.
- Light and aurora-light themes use warm-white surfaces with dark text; dark and aurora-dark themes use graphite surfaces with light text.
- Normal text and input text must meet WCAG AA contrast of at least 4.5:1 against their rendered surface.
- Preserve blue-purple primary actions and green connected-state semantics, using NAS-scoped darker/lighter tones where needed for WCAG AA readability.
- Publish only task-owned commits based on `origin/main`; do not include the caller's four local `main` commits or untracked `latest.json`.
- Docker image version and desktop source metadata are exactly `2.9.2`.
- The new container's `/api/build` identity and OCI config labels report `2.9.2`; the Update page therefore shows current `v2.9.2` and checks `ghcr.io/wuli2025/polaris_coworker:latest`, never the retired `llmwiki.cloud/downloads/docker` path.
- A 2.7 NAS requires one manual bootstrap because 2.7 contains neither the updater script nor updater sidecar compose file.
