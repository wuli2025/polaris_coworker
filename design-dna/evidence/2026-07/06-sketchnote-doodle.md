# Sketchnote / RSA Animate 手绘涂鸦（手绘涂鸦大师的元教材）

## 一句话：它凭什么好
「边说边画」降低观众防御——工整的手绘线、一套稳定的涂鸦符号、单一强调色，让内容像有人在白板现场画给你看，天然专注、天然信任。

## 解构数据（实测）
- **五基本形**：□ ○ △ 线 点——组合出一切图标（Rohde《Sketchnote Handbook》）。图标标准是「你和读者都看得懂」，不是画得像艺术品。
- **线条**：等宽针管笔（fineliner），**慢下来一笔一画求工整**，不是求潦草——这是手绘与乱涂的分界。
- **涂鸦符号字典（元素→义，全篇复用）**：💡灯泡=想法 / ➜箭头=因果流向(最高频) / ⭐星=关键 / 🚩横幅banner=章节标题 / ▢容器=打包成组 / ——连接线=关系 / 💬气泡=引语 / 👤简笔人=角色 / ➕➖✓✗=优缺对错。
- **马克高亮色（单一强调，只用 1 种）**：黄 `#FFD93B`~`#FFE44D`（灯泡涂黄最典型）/ 橙 `#F5821F`~`#FF7A00` / 蓝 `#1E88E5`~`#2B7BB9`；灰阴影 `#B0B0B0`（Copic cool grey，不算颜色）。Ink Factory 起步 5 色：中浅灰/正红/正蓝/正绿/中紫 + 防蹭黑。
- **纸底**：白板白，或暖白/牛皮纸 `#FAF7F0`~`#F5EEDC` 显手作。
- **正文字体（← 挑战我 persona）**：sketchnote 传统**正文用手写体**（标题刷头笔粗横幅 + 正文高窄字形对比）。但用于「PPT 大众可读」场景，我 persona 坚持正文印刷体是对的取舍——记为**风格纯度 vs 可读性的取舍**，persona 选可读性 [A1 优先]。
- **结构骨架（选一种）**：线性 / 纵向栏 / 放射radial / 路径path / 模块分格modular / popcorn 散点。
- **圈重点四件套**：容器框打包 + 单一强调色 + 灰阴影立体 + 箭头引导 + banner 压标题。

## rubric 七维分
R1 4/5：印刷体正文保可读，马克高亮深浅需守。 R2 4/5：banner+箭头+单色高亮动线清楚。 R3 4/5：单强调+灰，克制和谐。
R4 4/5：五基本形 + 网格锚点稳。 R5 4/5：白板留白足。 R6 5/5：符号字典全篇一致。 R7 5/5：像人现场画，亲切记忆点强。

## ★ 印证 / 挑战
- **印证** persona 三招全部有据：抖线边框=工整手绘线 [A11]；涂鸦字典=符号一符一义 [A11]；马克高亮=单一强调色 [A8]。
- **修正/补强**：① 强调色「一页主用一色」升级为**全篇只用 1 种马克色 + 灰阴影**（比原「一页 ≤3 涂鸦符号」更该管的是颜色数）；② 补「结构骨架六选一，先定骨架再涂」到版式（原缺，正是「无骨架乱摆」反模式的解药）；③ 圈重点四件套写进署名版式；④ 保留「正文印刷体」但版本志注明这是对 sketchnote 传统的**刻意取舍**（可读性优先）。
