# Vercel Geist 设计系统（极简黑大师的元教材）

## 一句话：它凭什么好
把「克制」做成了一套可下载的 token 系统——纯黑纯白 + 一个蓝 + 一根 8% 白边，零装饰却贵气逼人，是开发者极简风的工业标准。

## 解构数据（实测 token）
- **背景/前景**：`#000000` 纯黑 / `#FFFFFF` 纯白（← 修正：我原 persona「禁纯黑」过绝对，Vercel 正是纯黑；Linear 才用暖近黑。两条路都成立）
- **单强调**：`#0070F3`（蓝，仅链接/主按钮/激活态）；Linear 版用紫 `#5E6AD2`~`#7C5CFC`
- **灰阶 ramp（10 级）**：#F7F7F7 / #E5E5E5 / #D4D4D4 / #A3A3A3 / #737373 / #525252 / #404040 / #262626 / #171717 / #0A0A0A —— 层级全靠这一条灰阶，不靠彩色
- **边框**：默认 `rgba(255,255,255,0.08)`、加强 `rgba(255,255,255,0.15)`（← 印证我 persona 的「8–12%」几乎精确命中）
- **字体**：Geist Sans（回退 -apple-system/system-ui）+ Geist Mono（回退 SFMono）—— 等宽是第二声道，印证
- **字号**：12 / 14 / 16 / 18 / 24 / 32 / 48 / 64（← 注意：不是严格等比模数，是「实用跳档」；我 persona 的 1.333 模数需放宽为"跳档也合法"）
- **字距**：display 级 `-0.04em`、常规 `-0.01em`（← 我 persona 缺这条，应补：深色大字必须收紧字距）
- **行高**：1.15 紧 / 1.5 基 / 1.625 松
- **间距**：4/8/12/16/24/32/48/64/96/128（8px 制，印证）
- **圆角**：0 / 4 / 6 / 8 / 9999（← 印证 persona「圆角 ≤8px」精确成立；0px 是首选）

## rubric 七维分（每维一句证据句）
R1 5/5：纯黑白 21:1 对比，灰阶层级清晰。 R2 5/5：单强调色 + 灰阶做焦点，动线唯一。
R3 4/5：色彩极简到近乎无彩，克制满分但"和谐"维度天然受限。 R4 5/5：8px 制 + Geist 字阶工业级严整。
R5 4/5：留白充裕但营销页节奏感一般。 R6 5/5：token 全局一致，零冗余装饰。 R7 5/5：一眼 Vercel，气质与开发者受众严丝合缝。

## ★ 印证 / 挑战
- **印证** [A10 克制][A11 一致]：边框 8% 白、单强调、0 装饰 —— 极简黑 persona「1px 信仰/单色聚焦」三招全部有据。
- **印证** persona 具体值：边框 8–12% ✓、圆角 ≤8px ✓、等宽第二声道 ✓、强调紫≈Linear ✓。
- **挑战** persona 两处需修：① 「禁纯黑 #000」太绝对——Vercel 用纯黑，应改为「纯黑（Vercel 派）与暖近黑（Linear 派）皆可，二选一」；② 字阶「1.333 模数」应放宽为「实用跳档亦合法」，并**补一条**：display/大标题字距收 -0.04em、常规 -0.01em。
- **暴露空白**：persona 未规定灰阶 ramp——应补一条「层级用一条 10 级中性灰阶承载，禁止用彩色做层级」。
