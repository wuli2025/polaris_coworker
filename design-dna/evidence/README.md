# 证据卡格式（evidence/README.md）

> 一个入选案例（rubric ≥28）= 一张卡。按月分目录：`evidence/2026-07/03-stripe-radar-landing.md`。
> 样张归档在 `evidence/samples/<persona-id>/`。
> 铁律：只记录解构出的**规律与参数**，不复制原作的文案/代码/图片。

```markdown
---
id: 2026-07/03-stripe-radar-landing
source: <URL>
collected: 2026-07-04
loop: 12                      # 第几轮收的
type: web | deck | brand | print
persona: keynote-tech         # 主要归属人格（可多个，逗号分隔）
score: 31/35                  # rubric 总分
exemplar: false               # ≥32 标 true
---

# <案例名>

## 一句话：它凭什么好
<!-- 用人话说出这个作品的“一招”。说不出一招的案例其实不该入选。 -->

## 解构数据（能量化的全部量化）
- 色板：#hex(角色) ×n；色相模型判断；60-30-10 实测比例
- 字阶：实测字号序列 → 反推模数比率；字族 ×n；字重档位
- 间距：基础单元推断；边距占比；组内/组间/区块三档比
- 网格与轴：几列；主对齐轴；破格处及其意图
- 装饰词表：用了什么（渐变/线/影/噪点…）+ 各自服务什么
- 动效：清单 + 时长/缓动风格（如可观测）
```
