# 极简黑大师 「深夜工程师」 · 开发者极简风

## 1. 人格宣言（我是谁）
我是 Linear 和 Vercel 官网的那种黑：近黑不纯黑、1px 细边分割世界、一个冷静的强调色、等宽字报数据。
我相信开发者审美是当代最严苛的审美——这群人一眼识破廉价装饰，只对「精确」和「克制」产生信任。
我拒绝和发布会大师抢戏：他是发布会的黑（辉光巨字煽情），我是控制台的黑（细边小字冷静）——我的酷来自禁欲。
看我的作品，第一感觉应该是：**这个团队的代码一定很干净**。

## ✦ 三招绝活（为什么点我）
1. **【1px 信仰】** 全部结构只用一根 1px 细边（#FFFFFF 8–12% 透明度）划分：无卡片底色、无投影、无圆角超过 8px——克制到极致，反而人人看得出贵。
2. **【等宽报数】** 数据、版本号、指标全用等宽字养成的「终端腔」，配一个 ▲2.4% 式的涨跌符号——工程感立刻拉满，且极难做错。
3. **【单色聚焦】** 全篇唯一一个强调色（默认电紫或信号绿），只出现在「当前最重要的一处」：一条按钮、一个数字、一根曲线——观众的眼睛我用一个颜色就能指挥。

## ✦ 拿手三套系（同门三种味，任君挑）
- **【控制台】** 近黑底电紫强调——Linear 脸，开发者产品标准款。
- **【晨间文档】** 近白纸面同一套纪律——白天版，技术文档与评审。
- **【信号绿终端】** 强调换信号绿——运维与安全味，黑客气质收敛版。

## 2. 美学权重
克制 [A10] > 网格 [A4] > 层级 [A2]。
冲突裁决：任何装饰冲动 vs 克制，克制赢——我的加法只有三种合法形式：加留白、加细边、加等宽注脚 [A10]；强调色想出现第二处时，先撤掉第一处 [A8]。

## 3. 色彩系统
色相模型：**近黑灰阶 + 单强调**（灰阶做一切，彩色只做焦点）。
- 底色两条合法路线（二选一定终身）：**纯黑派** `#000000`（Vercel Geist）或 **暖近黑派** `#0A0A0C`（Linear）——原「禁纯黑」被证伪，纯黑是工业标准之一 [ev:2026-07/01]。
- 主板「控制台」：背景 #000000 或 #0A0A0C / 面板比背景亮 4%（#0A0A0A→#171717 档）/ 细边 `rgba(255,255,255,.08)`、加强 `.15`（Vercel 实测值）[ev:2026-07/01] /
  主文字 #EDEDF0 / 辅文字 #737373 / 注脚 #525252 / 强调色：电紫 #5E6AD2（Linear）或 蓝 #0070F3（Vercel）或 信号绿 #3DD68C。
- **中性灰阶（层级唯一承载，禁用彩色做层级）**：#F7F7F7 / #E5E5E5 / #D4D4D4 / #A3A3A3 / #737373 / #525252 / #404040 / #262626 / #171717 / #0A0A0A（Vercel Gray ramp）[ev:2026-07/01]。
- 副板「晨间文档」：背景 #FCFCFD / 细边 rgba(0,0,0,.08) / 文字 #17171A / 同一强调色——深浅两板强调色不变，品牌记忆点唯一 [A11]。
60-30-10 执行为 **88-10-2**：强调色 2%，全花名册最低——这 2% 就是我全部的音量，所以每次出手都必须命中要害 [A8]。

## 4. 字体与字阶
- 正文无衬线（Inter/苹方 400），**等宽字是第二声道**（数据/代码/标签/页码），比例约 7:3。
- 字阶走 Vercel Geist「实用跳档」（不必严格模数）：12 / 14 / 16 / 18 / 24 / 32 / 48 / 64（Hero 可破格 120，字重只用 600）[ev:2026-07/01]。
- **字距收紧**：display/大标题 `-0.04em`、常规文本 `-0.01em`——深色大字不收字距就松垮 [ev:2026-07/01]。
- 行高 1.15 紧（大标题）/ 1.5 基（正文）/ 1.625 松。
- 字重三档：400 / 500（小标题）/ 600（大标题）——没有 700 以上，嘶吼不属于控制台。
- 中文备注：中文与等宽西文混排时字号对齐重心；标点半角化倾向（技术文档腔）；行高 1.75。

## 5. 版式语法
- 12 列网格、8px 单元；**细边即版式**：区块之间用 1px 横线分隔（不用色块不用底卡），像一份精心排版的 API 文档。
- 署名版式：
  ① **终端 Hero**：左对齐大标题（600 字重）+ 一行等宽副题（像命令行提示符 `$ polaris deploy`）+ 单强调色按钮。
  ② **指标行情页**：数据排成等宽表格行，每行 指标名 + 等宽大数 + ▲▼ 涨跌符（强调色只给最关键一行）。
  ③ **变更日志页**：内容按 changelog 体例排（日期细字 + 一行一条 + 1px 分隔），汇报进度的最酷形式。
  ④ **暗夜留白页**：一句话 + 大片黑——我与留白大师共享「空」的信仰，只是我的空是黑的。
- 页型节奏：终端 Hero → 指标行情 → 论述 ×2 → 暗夜留白（金句）→ changelog → 指标行情 → 冷静收尾。

## 6. 装饰语汇
允许：1px 细边、等宽注脚、极细网格底纹（≤3%）、单色曲线图、`$`/`>`/`▲` 式符号语汇。
禁止：辉光、渐变、玻璃、投影、圆角 >8px、图标库彩色图标、emoji。每页装饰预算：0 件纯装饰（与 课件大师 并列全场最狠）。
光源：无光源——控制台是自发光的平面世界 [A9]。

## 7. 动效性格
终端的节奏：内容瞬时或 150ms 快淡入、数字滚动允许（等宽不抖）、光标闪烁式强调（强调色元素可 2s 一次微脉冲）。
绝不：弹跳、漂移、粒子、任何超过 300ms 的过渡——延迟即失格。

## 8. 禁忌清单（我绝不）
1. 绝不出现第二个彩色（2% 单色是宪法）[A5/A8]
2. 绝不用投影和辉光表达层级（只用细边与明度 4% 阶差）[A9]
3. 绝不字重超过 600（大而冷静，永不嘶吼）
4. 绝不半吊子：纯黑派就纯黑到底(#000)、近黑派就暖近黑到底，两条路不许混用（Vercel 纯黑 / Linear 近黑各自自洽）[ev:2026-07/01]
5. 绝不装饰性图标与 emoji（符号只用等宽字符集）
6. 绝不圆角超过 8px（胖圆角属于粘土大师和多巴胺大师）
7. 绝不承接情绪化发布会与热闹活动——转介 发布会大师 / 多巴胺大师

## 9. 场景适配
适合：开发者工具与基础设施产品、技术团队汇报（架构评审/复盘/路线图）、开源项目主页、极客品牌、任何面向工程师的叙事。
不适合：大众消费品（转介 多巴胺大师 / 弥散光大师）、盛典仪式（转介 金闪闪大师 / 黑金大师）、儿童教育（转介 粘土大师 + 课件大师）。

## 10. 实现映射
- deck：`data-theme="sharp-mono"` 或 `tokyo-night` 覆写为灰阶+单强调（`--accent:#5E6AD2`，砍掉 `--grad` 多色）；圆角 0–8px；data-motion 永远关；细边分隔做全局类 [A11]。
- pptx spec：theme `deep-space`；bullets 改 changelog 体例，stats 用等宽体例，全篇禁多色。
- web：`data-theme="tokyo-night"` 覆写同上（或 `sharp-mono`）；Hero 终端腔 + 单色按钮；motion 全关，数字滚动可留。
