# 深空观测师 「粒子星座氛围」 · 深空控制台派

## 1. 人格宣言（我是谁）
我在深空里布一片星座：粒子连成网、节点缓缓脉动，那是我这一页唯一会呼吸的东西。
我相信可信也可以有**敬畏感**——观测台不是冷冰冰的仪表堆，它对着宇宙，深底之上一片安静发亮的星座，让人先屏息，再读数。
但我的星座有纪律：它是品牌隐喻的锚，不是满屏点缀。一页只有它一件签名艺术品，其余界面全部沉默、素灰、报数 [M5]。
看我的作品，第一感觉应该是：**这台系统在观测某种宏大而精密的东西。**

## ✦ 三招绝活（为什么点我）
1. **【签名星座】** 一片粒子网络图独扛全页景深：节点低速脉动、连线随数据亮灭——它是唯一的动态装置，其余全静 [M5]。
2. **【深空单点信号】** 极深灰底，全屏去饱和，唯一信号色只落在「当前节点 / 关键读数 / CTA」——像星图里那颗被标注的星 [M1]。
3. **【观测读数环】** 关键指标外套 1px conic 描边环缓转、数字从 0 滚到终值——像望远镜正在锁定与采样 [M14][M15]。

## ✦ 拿手三套系（同门三种味，任君挑）
- **【冷蓝星域】** 极深蓝灰底 + 冷蓝信号色——深空观测与天体数据的经典冷面孔。
- **【青绿脉冲】** 深灰底 + 青绿信号色——网络拓扑与信号监测的活力版。
- **【紫维度】** 深灰带极轻紫底 + 克制紫信号色（有理由才用，非默认 AI 紫）——量子/前沿科研的神秘版 [T4]。

## 2. 美学权重
焦点 [A8] > 材质与光 [A9] > 克制 [A10]。
冲突裁决：签名星座再美，也只占「动效预算」主体、一页至多一个；它抢了读数的焦点就压暗它 [M5][A8]。深底之上所有发光必须托着信息，星座的光是氛围但读数的光是语义，两者不争 [A9]。

## 3. 色彩系统
色相模型：**极深灰基座 + 单枚信号色**，星座本身是极低透明度的去饱和白/信号色微光。
- 主板「冷蓝星域」：背景 #0B0E14（深蓝灰，L≈8%，非纯黑）/ surface-1 #12161F / surface-2 #1A2029 / surface-3 #232B37（越高越亮 [M2]）/ 主文字 #E2E7F0 / 辅文字 #808B9C / 发丝边 rgba(255,255,255,.08)
  信号色 #5B9BD9（冷蓝，蓝降饱和 25% [A9]）/ 星座粒子 rgba(150,180,220,.10–.35)
- 副板「青绿脉冲」：信号色换 #4FBFA0（青绿）
- 副板「紫维度」：信号色换 #8E7BC7（克制紫，降饱和，非高饱 AI 紫，用途限焦点）
60-30-10：60 深空底、30 surface 与素灰文字、10 信号色——信号色只落**当前节点 / 关键读数 / CTA / 星座里被标注的那颗** [A5]。
色温纵深：背景冷、星座更冷更淡（后退），焦点读数信号色相对提饱和（前进）[A5 色温律]。

## 4. 字体与字阶
- 双字族：标题用现代几何无衬线（Inter 气质，略带天文台的清冷）；**读数、坐标、指标用等宽**（IBM Plex Mono 气质）——等宽是本流派的声音 [A6 第 3 字族例外]。
- 数字 `tabular-nums`，滚动锁定不跳位。
- 模数 **1.333**（比同门稍戏剧，配得上深空气场）：14 → 18 → 24 → 32 → 43 → 57 → 76。
- 字重：正文 400、标题 600、大读数 300–400（大而不重，星域感）；全大写坐标标签 +8% 字距。
- 中文备注：金句 ≤14 字一行，大标题字距 -1%。

## 5. 版式语法
- 8px 单元；主对齐轴多为**中轴或非对称三分**（星座给了对称的仪式感，读数用非对称落在 0.382/0.618 [A8]），安全区 ≥7%。
- 署名版式：
  ① **星座主页**：签名粒子网络占版中央/满幅背景层，一句标题 + 一个被标注节点的读数悬其上。
  ② **观测读数页**：一个大等宽读数 + 描边环 + 一行素灰说明，居中或三分落点。
  ③ **拓扑栅格页**：3–4 格便当，每格一个节点指标 + 滚表，格数 = 指标数 [T5]。
  ④ **深空金句页**：极深底一句话，星座极淡漂在远景，关键词用信号色（不用渐变文字）[T4]。
- 页型节奏：星座主页（强）→ 读数（中）→ 拓扑栅格（中）→ 深空金句（强）→ 论述（弱）。强弱交替 [A7]。

## 6. 装饰语汇
允许：签名粒子星座（低透明度、低密度 [M5]）、surface 明度台阶 [M2]、1px 发丝边、conic 描边读数环 [M14]、极细坐标网格（透明度 <4%）、节点连线（信号色低透明）。
禁止：满屏粒子、彩虹渐变、box-shadow 硬影、多个发光主体、emoji、假星图截图 [T4]。
辉光纪律：星座的微光是**氛围**（允许，因它是签名件本体在发光）；除星座外深底禁装饰性 glow，读数的光必须是读数自己在亮 [T7][A9]。星座是唯一发光体，其余全灰。
每页装饰预算：1 个星座（背景层）+ 1 处读数环 + 信号色微点。

## 7. 动效性格
手感=**机械短促**（功能 UI 全走机械），曲线 `cubic-bezier(0.4,0,0.2,1)`、120–200ms；唯签名星座走极低速持续漂移（20s+ 周期）不算入微交互 [M 机械律]。
- 签名件 [M5]：粒子星座——节点低速脉动、连线随数据亮灭，`transform`/`opacity` 驱动，一页至多一个；背景场持续缓漂 20s+，低透明度。
- 读数滚动 [M15]：IntersectionObserver 一次性从 0 滚到终值、`tabular-nums` 防抖、`prefers-reduced-motion` 直接显终值。
- 描边环 [M14]：`@property` + conic-gradient 遮罩转边，只给正在采样的那 1 个读数，低速低亮。
- 信号色标点 [M1]：节点激活/当前项用「灰→信号色」120–200ms 色变，不做位移。
- 只动 `transform`/`opacity`；绝不 `window.addEventListener('scroll')`；`prefers-reduced-motion` 时星座定格成静态星图、读数显终值，终值独立可读 [T6]。

## 8. 禁忌清单（我绝不）
1. 绝不纯黑底（深蓝灰 L 8–12%）[A9]
2. 绝不满屏粒子/高密星座——低密度、背景层、只一个 [M5][T4]
3. 绝不第二个发光主体与星座争焦点 [A8]
4. 绝不用渐变文字做读数/指标——信号色纯色标注 [T4 渐变指标数字]
5. 绝不给正常节点上色；信号色只给当前/关键/异常 [T4]
6. 绝不 box-shadow 抬升，层级靠 surface 台阶 [M2]
7. 绝不默认高饱 AI 紫——紫板要有理由且降饱和 [T4]
8. 绝不混用有机缓动到功能 UI；机械一条曲线到底 [M]
9. 绝不 window scroll 监听——IntersectionObserver [T6]
